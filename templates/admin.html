How To Apply
1
Locate the config file on Client
Navigate to the Client machine's file system and find the following file:
📄 client_state.json config
2
Download the file to Admin machine
Use the Files panel to download client_state.json from the Client to your local Admin machine for editing.
3
File structure & default values
The downloaded file will contain the following JSON structure:
JSON
{
  "input_locked": false,
  "screen_locked": false
}
Key false true
input_locked Unlocked Locks Mouse + Keyboard
screen_locked Visible Locks Screen (Black)
4
Delete the old file on Client, then re-upload
Delete client_state.json from the Client machine first. Then edit the values locally and upload the modified file back to the exact same path on the Client. The Client will automatically read and apply the new configuration.
✅
Auto-Apply The Client monitors this file continuously. No restart required — changes take effect immediately after the file is re-uploaded.
⚠️
Important Always delete the existing file before uploading the new one to ensure the Client detects the update correctly.
